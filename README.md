## Sobre o curso

**Pós-Graduação em Engenharia de IA Aplicada** é um curso de especialização em integração de modelos avançados de IA em sistemas reais oferecida pela [UNIPDS](https://unipds.com.br/org-pos-ia/). O curso aborda os principais pilares da Engenharia de IA Aplicada, incluindo:

- Fundamentos de IA e LLMs para Programadores
- APIs de IA Generativa e Prompt Engineering
- MCP – Model Context Protocol
- Criação de Agentes Autônomos
- Ferramentas de IA para UX & UI
- Ferramentas de IA para DevOps
- Ferramentas de IA para Gestão de Projetos
- Arquitetura de Sistemas com IA
- Processamento de Dados e Fine-Tuning
- Segurança e Governança em IA
